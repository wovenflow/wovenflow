# Edit: Add an optional `options.collapseParagraphs` flag

Extend `normalize(text)` so it accepts a second optional `options` argument — an object that may carry a `collapseParagraphs` boolean. When `options.collapseParagraphs` is `true`, paragraph breaks are not preserved: the whole input collapses into a single paragraph, so every run of whitespace including blank-line breaks becomes a single space and the result contains no `\n` characters. All other rules are unchanged — leading/trailing whitespace is trimmed and runs of whitespace within the text collapse to a single space. When `options` is omitted, is `undefined`/`null`, or has a falsy `collapseParagraphs`, the function behaves identically to the original: paragraph breaks (two or more consecutive newlines) are preserved as exactly one blank line (`\n\n`) between paragraphs. The function still accepts any string input including the empty string. Export the same single `normalize(text, options)` function from `index.js`.
