# Normalize whitespace

Implement a function `normalize(text)` that takes a string and returns a normalized version. Within each paragraph, runs of whitespace (spaces, tabs, single newlines) collapse to a single space, and leading/trailing whitespace on the paragraph is trimmed. Paragraph breaks (two or more consecutive newlines) are preserved as exactly one blank line between paragraphs (so paragraphs are separated by `\n\n` in the output). Leading and trailing blank lines in the overall input are removed. The function should accept any string input including the empty string.

Export a single function `normalize(text)` from `index.js`.
