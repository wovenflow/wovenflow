# Edit: Add alias map option and a complementary stringifyFlags export

Extend `parseFlags(argv, options)` to accept an optional second argument `options` with an `aliases` property — an object mapping short flag characters to long flag names (for example `{ v: "verbose", o: "output" }`). When a short flag character has an entry in `aliases`, the resulting key in the `flags` object is the aliased long name instead of the single character; combined short flags `-xyz` apply aliasing per character. When `aliases` is absent or a character is not listed, behavior is unchanged. Additionally, export a new function `stringifyFlags(parsed)` from `index.js` that takes an object of the same shape returned by `parseFlags` (with `flags` and `positional`) and returns a normalized `argv`-style array using long-flag `--name=value` form for string values, bare `--name` for boolean true values, repeating the flag for array values, and appending positional arguments in order at the end.
