# Edit: add comparison helper for parsed semver values

Extend the module to also export a `compare(a, b)` function from `index.js` that compares two semantic-version strings using the same shape `parse(input)` already accepts. Each argument is a string in the form `MAJOR.MINOR.PATCH` with the optional pre-release and build segments described previously; `compare` parses both sides (reusing the existing rejection behavior for malformed inputs) and returns `-1` if `a` precedes `b`, `1` if `a` follows `b`, and `0` if they are equal. Precedence follows the standard semver ordering: compare `major`, then `minor`, then `patch` numerically; a version without a pre-release outranks one with a pre-release at the same `MAJOR.MINOR.PATCH`; when both sides have pre-release identifiers, compare them dot-segment by dot-segment, with numeric segments ordered numerically, alphanumeric segments ordered lexicographically, numeric segments ranking below alphanumeric ones, and a shorter identifier list ranking below a longer one when all leading segments match. Build metadata is ignored for ordering. The original `parse(input)` keeps its exact signature and behavior.
