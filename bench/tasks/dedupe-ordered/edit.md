# Edit: Add an optional `keyFn` to dedupe by a derived key

Extend `dedupe(items)` so it accepts a second optional `keyFn` argument — a function that derives a comparison key from each item. When `keyFn` is provided, two items are considered duplicates if `keyFn` returns the same key for them (compared by the same rules the original used: strict equality for primitive keys, with `NaN` keys treated as equal to other `NaN` keys). The first item that produces a given key is kept and subsequent items producing that same key are dropped, preserving order of first occurrence. The kept value is always the original item, not the derived key. When `keyFn` is omitted, `undefined`, or `null`, the function behaves identically to the original — deduplicating by the item itself (strict equality for primitives, reference identity for objects/arrays, NaN-collapsing). Export the same single `dedupe(items, keyFn)` function from `index.js`.
