# Edit: Add a `cancel` method on the throttled function to discard a pending trailing call

Extend `throttle(fn, ms)` so that the returned throttled function additionally exposes a `cancel()` method. Calling `cancel()` discards any pending trailing-edge invocation that was scheduled but has not yet fired, clears the current throttle window, and resets the throttled function so that the very next call invokes `fn` immediately as a fresh leading edge. If `cancel()` is called when no trailing-edge call is pending, it still resets the window so the next invocation fires immediately; calling `cancel()` when the throttled function has never been called is a harmless no-op. The `cancel` method takes no arguments and returns `undefined`. All existing leading-edge, trailing-edge, argument pass-through, and `this` binding behavior remain unchanged for callers that never touch `cancel`. Export the same single `throttle(fn, ms)` function from `index.js`; the `cancel` method is attached to each returned throttled function instance.
