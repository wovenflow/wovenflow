# Edit: Add optional comparator argument for typed containers

Extend `deepEqual(a, b, options)` to accept an optional third argument `options` that, when provided, enables structural equality for `Map`, `Set`, and `Date` instances in addition to the existing behavior. When `options.collections` is true, two `Date` instances are equal if their `getTime()` values are equal (with `NaN` time matching `NaN` time), two `Set` instances are equal if they have the same size and every element of one has a deeply-equal counterpart in the other, and two `Map` instances are equal if they have the same size and every key in one maps to a deeply-equal value under a deeply-equal key in the other. When `options` is omitted or `options.collections` is falsy, behavior is unchanged: `Map`, `Set`, and `Date` instances compare as plain objects. Cyclic references inside these collections must still terminate. The exported signature remains `deepEqual(a, b, options?)` from `index.js`.
