# Edit: Add an optional `valueFn` to transform grouped values

Extend `groupBy(items, keyFn)` so it accepts a third optional `valueFn` argument — a function applied to each item to produce the value that gets stored in its group, in place of the item itself. Grouping still works exactly as before: `keyFn` derives the group key, items that produce the same key go into the same group, and the original input order is preserved within each group. When `valueFn` is provided, each group holds `valueFn(item)` for its items instead of the raw items (order still matches input order). When `valueFn` is omitted, `undefined`, or `null`, the function behaves identically to the original — each group holds the raw items. Export the same single `groupBy(items, keyFn, valueFn)` function from `index.js`.
