# Group by

Implement a function `groupBy(items, keyFn)` that takes an array of items and a function that derives a key from each item, returning an object whose keys are the derived keys and whose values are arrays of items that produced that key, preserving the original order within each group. Items in the input that produce the same key go into the same group. The function should accept any array, including an empty array, and any key function that returns a primitive (string, number, boolean).

Export a single function `groupBy(items, keyFn)` from `index.js`.
