# Edit: Add a `count(now)` method to the window

Extend `createWindow(ttlMs)` so the returned object additionally exposes a `count(now)` method. `count(now)` returns the number of values still within the TTL window relative to `now`, using exactly the same window rule as `sum`: a value is counted when its recorded timestamp is strictly greater than `now - ttlMs` (so a value recorded at `now - ttlMs` is excluded, and one at `now - ttlMs + 1` is included). `count` counts entries, not summed magnitudes — three separate `add` calls that are all in-window contribute `3` to the count regardless of their values (including zero or negative values). With no values in window, `count` returns `0`. Like `sum`, `count` takes the current time as an argument and must not depend on real wall-clock time. The existing `add(value, now)` and `sum(now)` methods keep their exact signatures and behavior. Export the same single `createWindow(ttlMs)` function from `index.js`.
