# Edit: Add page-based access via `page` and `pageSize` options

Extend `paginate(items, options)` to additionally accept an opt-in `page` (1-indexed) together with `pageSize` as an alternative to `offset` and `limit`. When `page` is provided, compute the effective offset as `(page - 1) * pageSize` and the effective limit as `pageSize`; the returned object includes the existing fields plus `page` (the page that was applied, clamped to a minimum of 1 so values less than 1 are treated as 1), `pageSize` (the page size that was applied), `totalPages` (the ceiling of `total / pageSize`, or `0` when `pageSize` is less than or equal to zero), and `hasMore` reflecting whether further pages remain. If both `offset`/`limit` and `page`/`pageSize` are supplied, `page`/`pageSize` takes precedence. Calls that pass only `offset` and `limit` continue to return exactly the original shape and values.
