# Edit: Add an optional `maxLength` parameter to `slugify`

Extend `slugify(input)` so it accepts a second optional `maxLength` parameter — a positive integer that caps the produced slug at that many characters. When `maxLength` is provided, the result is truncated at the boundary of the last complete word-segment that fits within the limit: if the slug after normal processing is longer than `maxLength`, drop trailing characters until the result is at most `maxLength` characters, then trim any trailing hyphen so the truncated slug does not end with `-`. When `maxLength` is omitted, `undefined`, or `null`, the function behaves identically to the original (no truncation). A `maxLength` of `0` or a negative value is treated the same as omission (no truncation) — the function never produces an empty slug solely because of the cap. All existing lowercase, separator-collapse, leading/trailing-trim, and non-ASCII behavior remain unchanged when `maxLength` is not supplied. Export the same single `slugify(input, maxLength)` function from `index.js`.
